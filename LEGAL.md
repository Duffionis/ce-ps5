# Legal notes

ce-ps5 is an independent project and is not affiliated with Sony.

- It contains no firmware, keys, games, SDK files or leaked documents, and it never will.
- It only runs unencrypted programs (homebrew and our own tests). It does not decrypt commercial files.
- All code is written from public knowledge (FreeBSD behaviour, public homebrew SDKs, public hardware documentation).
- Contributors must not use leaked or NDA material. By contributing you confirm you didn't.
- This is not legal advice.
